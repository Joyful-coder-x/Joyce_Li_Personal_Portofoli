# Work Plan

## Phase 1: Initial Concept (Completed)
- Define the artistic vision and overall concept for the portfolio.
- Research aesthetics: ceramics, jewellery, engineering, Van Gogh, bubble art.
- Sketch initial layouts and create moodboards.
- Determine project themes and section structure.

## Phase 2: Design Iteration & Asset Creation (Completed)
- Experiment with AI‑generated backgrounds and textures.
- Extract icons and decorative elements.
- Test multiple colour palettes and typography options.
- Organize assets into a structured library.
- Update product specification based on findings.

## Phase 3: Integration & Deployment (In Progress)
- Build the website structure in code (HTML/CSS/JavaScript).
- Integrate final assets into the templates.
- Document the workflow with README and product spec.
- Prepare presentation materials summarising the process.

## Remaining Tasks
- Refine responsive design and accessibility features.
- Conduct user testing and refine based on feedback.
- Deploy the website on GitHub Pages or another hosting platform.
- Create a final case study summarising the project outcomes.
