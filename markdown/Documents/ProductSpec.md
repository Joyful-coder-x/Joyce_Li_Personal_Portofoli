# Product Specification

## Project Overview
This personal portfolio website showcases work across ceramics, jewellery, and engineering. The site emphasises a handcrafted, sketchbook aesthetic, featuring hand‑drawn textures and AI‑assisted imagery while maintaining a cohesive identity. The purpose is to communicate creative skills, technical expertise, and design process.

## Key Requirements
- Responsive design that adapts to desktop and mobile devices.
- Navigation structure: Home, About, Work Experience, Projects (with subpages for each of the three project themes), and Contact.
- Visual system rooted in a sketchbook feel with warm, earthy colors and organic shapes.
- Integration of AI‑generated assets (backgrounds, icons) that complement the handcrafted aesthetic.
- Clear presentation of project process and outcomes, including phase summaries and assets.
- Accessibility considerations: readable fonts, sufficient contrast, and keyboard navigation support.

## Functional Features
- Scroll‑based navigation with subtle animations and transitions.
- Project pages with image galleries, descriptions, and links to source code or external resources.
- Contact form for visitors to reach out.
- Optional blog or news section for updates and reflections.

## Constraints & Assumptions
- All content and images must respect copyright; AI‑generated assets are created exclusively for this portfolio.
- The website will be hosted using a static site provider (e.g., GitHub Pages).
- The primary audience includes potential clients, collaborators, and recruiters interested in creative and technical work.
