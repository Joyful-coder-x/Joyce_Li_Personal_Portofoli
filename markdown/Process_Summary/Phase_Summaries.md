# Project Process Summary

## Phase 1: Initial Concept
- Purpose: define the artistic direction and structural outline of the portfolio website.
- Activities:
  - Brainstormed and refined the core idea of the personal portfolio.
  - Gathered inspiration from ceramic, jewellery, engineering, Van Gogh, and bubble styles to explore possible aesthetics.
  - Created moodboards, color palettes, and style references.
  - Sketched rough layouts for the home page and key sections (about, work, projects).
- Outcomes:
  - Chosen visual direction combining handcrafted and sketchbook feel.
  - Identified three project themes: ceramic, jewellery, and engineering.
  - Drafted the initial structure and planned navigation flow.
- Next steps:
  - Begin generating assets to test aesthetics and refine the chosen style.
  - Start drafting the workplan and product specification.

## Phase 2: Design Iteration & Asset Creation
- Purpose: iterate on design concepts, experiment with AI‑generated assets, and develop a coherent visual system.
- Activities:
  - Generated background textures (bubbles, starry Van Gogh patterns, engineering blueprints) using AI tools.
  - Extracted objects and icons from generated images and photographs.
  - Tested multiple layouts, colour schemes, and typographic treatments.
  - Organized assets into categories (backgrounds, icons, sketches, etc.).
  - Updated the workplan and product specification based on discoveries.
- Outcomes:
  - A set of cohesive assets aligned with the handmade/sketch style.
  - Draft layouts for the website sections and project pages.
  - Documented workflow for asset creation and iteration.
- Next steps:
  - Finalize a small set of assets for the final version.
  - Begin integrating assets into a working website structure.

## Phase 3: Final Integration & Deployment
- Purpose: assemble the refined assets and layouts into a functioning portfolio and prepare for deployment.
- Activities:
  - Structured the website using modern development tools (e.g., GitHub, VS Code).
  - Integrated final backgrounds, icons, and images into HTML/CSS templates.
  - Documented the workflow and created README, product spec, and workplan files.
  - Prepared project summary presentations and reflection (excluded from this archive).
- Outcomes:
  - A cohesive website structure ready for final adjustments.
  - Organized repository with code, assets, and documentation.
  - Defined a clear roadmap for remaining tasks.
- Next steps:
  - Refine responsiveness and accessibility of the website.
  - Perform user testing and iterate on feedback.
  - Deploy the site and document the final process in a case study.
